# Telegram admin bootstrap bot

Простой способ получить админа, когда база пустая или доступ только у владельца Telegram-бота.

## Как работает
- Бот отвечает **только** на Telegram user id, указанный в `BOT_OWNER_TELEGRAM_ID`.
- Команда `/getadmin`:
  - создаёт локальный аккаунт с логином `telegram_admin`, если он ещё не существует;
  - если аккаунт уже есть — сбрасывает пароль на новый случайный;
  - принудительно выставляет `role = 'admin'`;
  - снимает бан/reset флаги у этого аккаунта;
  - пишет действие в `admin_audit_logs`;
  - отправляет логин и пароль обратно в Telegram.
- После этого вы входите в веб-приложение с логином `telegram_admin` и полученным паролем — это и есть аккаунт с доступом в `/admin`.

## Нужные переменные окружения
Добавьте в `.env` на сервере:
```env
DATABASE_URL=postgresql://...
JWT_SECRET=...
TELEGRAM_BOT_TOKEN=...
BOT_OWNER_TELEGRAM_ID=123456789
# Опционально, если хотите использовать Telegram-файлы:
TELEGRAM_CHAT_ID=
```

`BOT_OWNER_TELEGRAM_ID` — это не username, а числовой ID вашего аккаунта Telegram. Узнать можно у @userinfobot или через другие Telegram-боты/клиенты.

## Запуск
Примените миграции приложения, затем запустите бота отдельным процессом на сервере:
```bash
npm install
npm run admin-bot
```
Ожидается, что PostgreSQL доступен по `DATABASE_URL`. Если база ещё не готова в момент старта, бот будет ждать подключение.

В Telegram откройте своего бота и отправьте:
```text
/getadmin
```
Бот вернёт логин и пароль вида:
```text
Логин: telegram_admin
Пароль: Abcdef123...
```

Затем:
1. Откройте веб-приложение.
2. Войдите с логином `telegram_admin` и присланным паролем.
3. В левом меню появится иконка щита `/admin`, либо открывайте `/admin` напрямую.

## Важно
- Бот хранит и показывает пароль только в ответе владельцу.
- Ротация `/getadmin` создаёт новый пароль и делает старый невалидным.
- Аккаунт `telegram_admin` нельзя зарегистрировать обычной регистрацией.
- Бот не даёт доступ другим пользователям Telegram, даже если они знают токен бота.
- Запускайте бота рядом с приложением на вашем сервере/VPS; в этой sandbox-среде он не имеет доступа к вашей реальной Telegram/PostgreSQL-конфигурации.
